## 项目事实基线

截至 2026-08-01：

- 前端已有 Vue 3 用户端、管理端页面和接口调用层，可作为交互原型与联调客户端。
- 后端为 Spring Boot 4 / Java 21 骨架，已实现 `GET /api/health`、统一响应对象、CORS、MySQL/JPA 配置与 Flyway 迁移基线。
- 数据库已有 17 张基础业务表，并初始化角色、权限、知识分类和标签；尚无对应业务接口与领域代码。
- 除健康检查外，前端引用的业务接口均未在本仓库后端实现。
- 当前不具备生产可用所需的认证授权、心理危机处置、隐私治理、审计、限流和可观测性能力。

## 文档维护规则

1. PRD 中需求使用 `FR-模块-序号`，非功能需求使用 `NFR-领域-序号`。
2. API 变更必须同步更新 `API.md`，禁止长期依赖前端多字段/多路径兜底。
3. 表结构变更必须通过版本化迁移脚本交付，`DATA_MODEL.md` 同步更新。
4. 每个里程碑开始前更新 `ROADMAP.md` 状态，结束后补充验收证据。
5. 涉及危机识别、用户隐私或管理端权限的变更必须单独评审。
