## 项目事实基线

截至 2026-08-03：

- Vue 3 用户端、管理端与 `/api/v1` 调用层已对齐，前端生产构建通过。
- Spring Boot 4 / Java 21 已实现认证/RBAC、日记、会话/SSE、本地规则式 AI、知识库、文件、分析、风险与审计接口。
- Flyway V1-V4、17 个 JPA Repository 与 Hibernate Schema 校验已在本地 MySQL 上通过。
- 代表性公共、用户和管理接口冒烟通过，401/403 权限负路径符合预期。
- 当前可用于本地演示和继续研发，但自动化测试、令牌生命周期、限流、真实模型安全评估、隐私生命周期、CI 与生产运维尚未达到上线门槛。

## 文档维护规则

1. PRD 中需求使用 `FR-模块-序号`，非功能需求使用 `NFR-领域-序号`。
2. API 变更必须同步更新 `API.md`，禁止长期依赖前端多字段/多路径兜底。
3. 表结构变更必须通过版本化迁移脚本交付，`DATA_MODEL.md` 同步更新。
4. 每个里程碑开始前更新 `ROADMAP.md` 状态，结束后补充验收证据。
5. 涉及危机识别、用户隐私或管理端权限的变更必须单独评审。
